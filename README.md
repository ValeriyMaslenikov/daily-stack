# daily-stack

Tools and practices from my daily dev stack — AI and otherwise.

These are personal notes: what I use, why, how, and where it bites. I keep them
for myself and share them in case they help someone else. Everything is written
from my own experience, so expect opinions, not reviews.

## Index

| Name | Category | What it's for | Status |
| ---- | -------- | ------------- | ------ |

**Status:** `daily` — part of my routine · `trying` — evaluating it · `dropped` — stopped using it (the page says why).

## Layout

- [`ai/`](ai/) — AI tools: coding agents, plugins, skills, MCP servers.
- [`practices/`](practices/) — workflows that span several tools.

More categories (terminal, editor, git, infra, …) appear as I write about them.
See [`_template.md`](_template.md) for how an entry is structured.
